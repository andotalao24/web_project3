# PantryPal 🥫

A full-stack web app for tracking the food you have at home and managing a simple
grocery list. Add pantry items with a name, category, quantity, expiration date and
notes; sort by expiration so nothing goes to waste; keep a grocery list; and get
random "what could I cook?" suggestions from what you already own.

## Project Objective

Help busy people (students, parents, professionals) avoid buying duplicates, use
food before it expires, and remember what to buy — all in one lightweight app.
No external recipe API is used: suggestions are generated by shuffling the user's
own pantry items.

## Tech Stack

- **Backend:** Node.js + Express + native MongoDB driver
- **Auth:** Passport (local strategy) with express-session
- **Frontend:** React (function components + Hooks) + Vite, PropTypes, Bootstrap 5 (CSS)
- **No** Mongoose, axios, or the `cors` package are used.

## Collections

- `pantryItems` — food already at home (name, category, quantity, expiration, notes)
- `groceryItems` — food to buy (name, category, quantity, purchased)
- `users` — accounts for Passport authentication

Both `pantryItems` and `groceryItems` support full CRUD.

## Build & Run

### 1. Backend

```bash
cd backend
cp .env.example .env        # then edit .env with your Mongo connection string
npm install
npm run seed                # populate 1000+ synthetic records
npm start                   # starts API on http://localhost:5000
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev                 # starts React app on http://localhost:5173
```

The Vite dev server proxies `/api` requests to the backend
(see `frontend/vite.config.js`), so sessions work same-origin.

### 3. Lint & Format

```bash
# from either backend/ or frontend/
npm run lint
npm run format
```

## How to Use

1. **Register / Log in** on the landing screen.
2. **Pantry** — add what you have. Use the *Sort by expiration* button to see what to
   use first. Edit or delete items as you cook and shop.
3. **Grocery List** — add things to buy, adjust quantities, tick items as purchased,
   and remove them after shopping.
4. **Suggestions** — click *Surprise me* for a random food combination from your
   pantry, or pick a category.
